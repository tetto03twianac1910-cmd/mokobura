# テーマ制作仕様（デザイン生成AI向け）

## 統一画風
- 参考イメージ: 出水ぽすかのような世界観。ただし模倣ではなく方向性として。
- よりシンプルに、よりクリアに。**引き算を大事に**: 色数は絞る、線はきれいに、余白を残す。
- 9テーマ全てで画風・線の太さ・塗りの質感を統一する。テーマが違っても「同じ作品の世界」に見えること。

## 各テーマに必要な素材
1. 壁紙（新規タブ背景）: 1920×1200 以上、中央〜下部は検索UIが乗るため静かに。主役モチーフは左右どちらかに寄せる。
2. 相棒キャラ／モチーフの小イラスト（任意）: PNG想定、新規タブの隅に置く用。
3. 配色は `src/themes/themes.js` の colors が正。絵のトーンはそれに合わせる。

## 禁止・注意
- 既存キャラクターや商標を描かない。

- 文字は絵に入れない（UI側で出す）。

## ブランドとしての設計原則（配色哲学）

デザインは一回の作り替えで終わらせず、改善し続けながらブランドを育てる。
配色を変更するときは、必ずこの原則との整合を全テーマ横断で点検すること。
（2026-11-21 の配色全面見直しで策定。これが第一歩であり、原則自体も育てる対象。）

### 1. 彩度の扱い
- 原則として中〜低彩度。色は自然素材（苔・樹皮・深水・月光・和紙・土）から採る。
  原色・蛍光色・安っぽいピンクは UI に持ち込まない。
- 例外テーマ（gamer-neon / bold-colors）でも、大胆さとビビッドさは**壁紙に委ね、
  UI は規律を保つ**。コンセプトの派手さと UI の品位は分離する。

### 2. アクセントの絞り方
- アクセントは **1テーマ1色**。その色がテーマの顔になる。
- `accent2` は同系色の補助トーン（アクセントの影・土台）に限定し、
  競合する第二の色相を持ち込まない。
- `onAccent` は accent を塗った面に載せる文字色。必ず accent との間で
  コントラスト 4.5:1 以上を確保する。

### 3. コントラスト基準
- 本文テキスト（text）は bg / surface に対して **7:1 を目標**（WCAG AAA 相当）。
- 補助テキスト（muted）も **4.5:1（WCAG AA）を死守**する。「薄くておしゃれ」より
  「読める」を優先する。検証は数値で行い、目視の印象で決めない。

### 4. テーマを跨いで統一する要素
- 明度ステップの作法: bg → surface → surfaceAlt は常に一段ずつ持ち上げる。
- 罫線の作法: border は surfaceAlt より一段だけ強い色。影ではなく線で分ける。
- タイポグラフィ: 見出しと挨拶は明朝系（Hiragino Mincho ProN / Yu Mincho / serif）、
  UI は端正なゴシック。丸ゴシックは使わない（可愛さは絵と色で出し、字形では出さない）。
- 角丸・余白のリズム・アクセントの使い方（塗る場所は主ボタンと選択表示だけ）。
- 遷移の速度感: テーマ切替は色が 0.45s で静かに移り、壁紙はクロスフェード。
  パッと切り替わる安っぽい変化はしない。

### 5. テーマごとに変える要素
- 色相ファミリーと明暗（dark / light）。
- アクセントのアイデンティティ（そのテーマを象徴する一色）。
- 壁紙の世界観とモチーフ。

### 7. 継続改善の約束
- 配色も原則も固定ではない。ユーザーの声と利用データを見ながら磨き続ける。
- 変更したら、その理由をこのファイルに残す。ブランドは記録の積み重ねでできる。
