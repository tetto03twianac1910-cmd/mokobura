## Zenn / Qiita 記事 構成案

タイトル案: 「着せ替えできる可愛いブラウザを Electron で作って公開した（もこブラ v0.1.0）」

1. **はじめに**
   - Simeji がキーボードに「可愛さ」を足して広がったように、ブラウザにも着せ替えを足したかった
   - 作ったもの: テーマ9種・全無料のPCブラウザ「もこブラ」。スクリーンショットと公式サイトへのリンク
   - 先に正直な注意: v0.1.0、署名なし、開発中

2. **技術構成**
   - Electron 内蔵 Chromium をそのまま使い、自前エンジンは持たない判断
   - タブ管理は WebContentsView、設定・履歴・ブックマークは端末内保存（サーバーなし）
   - テーマ定義を `src/themes/themes.js` の単一ソースにして、配色と壁紙を一括で切り替える仕組み

3. **着せ替えの実装で工夫したところ**
   - テーマ切替でタブバー・アドレスバー・新規タブページまで CSS 変数経由で一括変更
   - 新規タブページ: 壁紙全面表示＋時間帯のあいさつ＋検索＋ショートカット
   - 壁紙は全テーマで画風を統一（クリアな線、色数を絞る、余白を大事に）

4. **配布で苦労したところ（正直パート）**
   - electron-builder での Win / Mac / Linux パッケージング
   - 署名なし配布の現実: SmartScreen と Gatekeeper の確認画面、その案内文をサイトに書いた話
   - 署名（Apple Developer $99/年、Windows の証明書）を今後どうするか

5. **公開とこれから**
   - GitHub Releases + GitHub Pages でサーバーなし公開にした構成
   - 年内 1,000 ユーザーを目標にしていること、フィードバックを Issues で募集中であること
   - 次にやること: いただいた声の反映、テーマ追加

6. **おわりに**
   - リンク集（公式サイト / GitHub / Releases）
   - 感想・要望・スターのお願い（押し売りにならない温度で）

## note 紹介文（下書き）

タイトル案: 「毎日開くブラウザを、好きな世界に着せ替える。無料ブラウザ『もこブラ』を作りました」

---

ブラウザって、毎日いちばんよく開くアプリなのに、見た目はいつも同じで、ちょっと味気ない。

そんなふうに思って、「着せ替えできるブラウザ」を作りました。その名も「もこブラ」（仮名です）。

選べるテーマは9種類、ぜんぶ無料。

- 蜘蛛と鬱蒼とした森
- 鹿と暖かな森
- クジラと深い海
- 月と二人だけの宇宙飛行士
- 都会の大人可愛い女子の日常
- ゲーム女子とレトロなネオン空間
- 温かみのある和風な日本庭園
- 大胆な配色
- あなただけの美少女恋人

テーマを選ぶと、ブラウザの色も、新しいタブを開いたときの壁紙も、まるごとその世界に変わります。朝は「鹿と暖かな森」、夜は「クジラと深い海」、みたいに気分で着替えるのが楽しいです。

機能はふつうのブラウザとして使えるように、タブ・履歴・ブックマークを備えました。広告はアプリの中には入れていません。履歴などのデータも、あなたのパソコンの中にだけ保存されます。

正直にお伝えすると、まだ生まれたて（v0.1.0）の小さなアプリです。パソコンの初回起動時に「開発元を確認できません」という確認画面が出ます（個人で配っているアプリへの定番の確認で、手順は公式サイトに書きました）。至らないところも多いと思います。

だからこそ、使ってみた感想を聞かせてもらえたら嬉しいです。「このテーマが好き」「こんなテーマがほしい」だけでも大歓迎です。

ダウンロードは公式サイトから（無料・アカウント登録なし）。
https://tetto03twianac1910-cmd.github.io/mokobura/

あなたのブラウザが、ちょっとだけ好きな世界になりますように。
