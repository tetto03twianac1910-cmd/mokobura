# イラストレーター探し リサーチ結果（2026-11-21）

もこブラのテーマ壁紙9点を「お金のかからない」形で作り直すための調査。連絡はまだ取っていない。

## 結論サマリ

- **完全無償で「アプリに組み込んで不特定多数へ配布」まで許諾してくれる人は、表向きの募集としてはほぼ存在しない。** Xの無償依頼・無償リクエストは「個人利用限定・商用不可」が通例。無料アプリでも「配布利用」の許諾は個別交渉が必須。
- 現実解は次の3本柱:
1. **ココナラのモニター価格／お試しプラン**（実績作り目的の格安出品。1,500〜3,000円／点〜）。ただしモニター出品は商用利用NGの明記が多いので、**「商用利用可」明記か、事前にメッセージで配布利用の可否を確認**すること。
2. **Xで「実績作りのため無償／格安で描きます」「お仕事募集」と発信している新人・学生層へのDM交渉**。対価は金銭でなく「アプリ内・サイト・Xでのクレジット表記＋実績掲載OK＋紹介投稿」。まず1テーマだけ試作してもらう形が通りやすい。
3. **SKIMA／つなぐの低価格帯**（交渉可）。SKIMAは値下げ交渉が公式に認められている。
- 注意: 候補の多くは「キャラ1体」の価格。**背景付き壁紙一枚絵は別料金になりやすい**（例: つなぐでは背景描き込み+5,000円）。9点全部だと格安でも総額数万円規模になりうるので、**まず1点試作→画風が合えば継続依頼**が現実的。
- **Skebは不適**: 公式が二次利用・商用案件への利用を推奨しておらず、リテイク不可・事前相談不可のため、壁紙のような仕様指定が必要な案件には使えない。

## チャネル別: 実在性と条件

### 1. X（#無償依頼 #無償リクエスト #イラスト依頼 #お仕事募集）
- 実在: 活発。描き手側が「実績作りのため無償で描きます」と募集する投稿も定常的にある。
- 条件の実態: ほぼ全員が **個人利用限定**（アイコン・壁紙を自分で使う等）。著作権は描き手に帰属、クレジット表記必須が一般的。
- もこブラの場合: 無料アプリでも「作品をアプリに組み込み不特定多数に配布する」利用になるため、**投稿の条件をそのまま流用できず、DMで配布利用の可否を個別に確認・合意する必要**がある。ここを曖昧にするとトラブルの元。
- 探し方: 上記タグ＋「実績作り」「ポートフォリオ」で検索し、プロフィールに「お仕事募集」「DM解放中」とある人を優先。

### 2. ココナラ: モニター価格／お試しプラン
- 実在: 「実績を積むためモニター価格」と明記した出品が多数（下記候補参照）。1,500〜3,000円帯。
- 条件: 出品ごとにバラバラ。**商用利用NGを明記するモニター出品が目立つ**（候補3・4）。一方「商用利用可」を売りにする格安出品もある（候補1・2）。購入前にメッセージで「無料アプリの壁紙として組み込み配布する利用」が可能か確認必須。
- 著作権: 原則クリエイター帰属、利用許諾のみが通例。

### 3. ココナラ: 公開募集（リクエスト）
- 実在: 買い手が予算・条件を提示して提案を募る形式。実例: 歌ってみた用イラスト2点・予算6,000〜7,000円の募集に応募21人・閲覧919（2026年10月掲載）。
- 条件: 最低予算の設定があるため完全無料の募集はできないが、「無料アプリ・収益なし・クレジット表記と紹介つき」を明記すれば格安でも応募は集まる見込み。
- 「商用利用・用途拡大を追加料金なしで」等の条件を募集文に明記するのがこの形式の作法（実例募集もそうなっている）。

### 4. SKIMA
- 実在: 会員20万人超のコミッション特化サイト。相場はアイコン1,000〜10,000円、全体的に1,000〜6,000円帯が多い。
- 条件: **値段交渉が公式に可能**（「塗りを簡単にして安く」等の具体的な交渉が推奨されている）。商用利用は出品者ごとにオプション料金（+3,000円等）が通例。

### 5. つなぐ（tsunagu）
- 実在: 低価格帯のコミッションサイト。「商用利用OK」を明記した出品がある（候補6）。
- 条件: 出品ごとにオプション制（背景描き込み+5,000円等）。著作権は放棄されないのが通例。

### 6. デザイン学生・専門学生のポートフォリオ協力
- 実在性: 専門学校の産学連携は企業向け窓口が中心で、**個人の無料プロジェクトが使える公式チャネルは確認できなかった**。
- 実質的な経路は、学生・新人個人がXやココナラモニターで「ポートフォリオ掲載OKなら格安／無償」と活動しているケース。つまり上記1・2がその受け皿になっている。
